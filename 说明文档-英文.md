# InkNote — User Manual
Version v2.1.1 | Chrome Extension | https://github.com/gzmliang/mojian-extension

## 1. Overview

InkNote is a lightweight, professional Markdown reader and editor Chrome extension. No registration required. All data stored locally.

**Core Features (36 items):**

File Loading: Open local file / URL / drag-drop / context menu / recent files (20 max)
Rendering: Markdown(GFM) / LaTeX(KaTeX) / Mermaid diagrams / code highlight(190+ lang)
Edit Modes: Read / WYSIWYG / Source (auto-save)
WYSIWYG: Bold/italic/underline/headings/lists/quotes/code / Insert tables/images/links/hr / Undo/redo(50 steps)
TTS: Edge TTS(7 CN/EN/JP voices) / Browser TTS fallback / paragraph reading with highlight
AI Translate: Select text → AI translation / OpenAI-compatible API / configurable endpoint+key
Search: Full-text(case-insensitive) / match highlight / prev-next navigation
Navigation: TOC sidebar(auto-extract headings) / Bookmarks(position+snippet+timestamp) / Highlights(yellow marker)
Themes: Light / Dark / Sepia
Font: 8-36px adjustable
Export: HTML / PDF(print dialog) / Copy Markdown / Export log
Other: Fullscreen / Statistics(chars/paras/code/formulas/images/links/headings) / Debug log panel / Bilingual UI(CN/EN)

## 2. Installation

Search "InkNote" on Chrome Web Store (coming soon), or:
1. Download ZIP from GitHub Releases → extract
2. chrome://extensions → Developer mode → Load unpacked

## 3. Quick Start

**Open documents (5 ways):**
1. Click toolbar icon to open blank page
2. Drag .md/.txt/.html files into window
3. Click "📂 Open File" or welcome screen button
4. Click "🔗 Open from URL" and enter link
5. Right-click .md link or selected text → "Open with InkNote"

**Layout:** Header(file name+buttons) → File info bar(size+stats) → Content area(Read/WYSIWYG/Source) → Floating toolbar(all features) → Debug panel(collapsible)

**Switch modes:** 📖Read(default) / ✏️WYSIWYG(Ctrl+E) / 📝Source. Ctrl+S saves WYSIWYG and returns to Read.

## 4. Rendering

Markdown → marked parse → Mermaid preprocess → KaTeX render → highlight.js highlight → Mermaid render

Inline math `$...$` and display math `$$...$$`. Mermaid: flowchart/sequence/class/state/pie/Gantt.

## 5. TTS

Configure Edge TTS server in Settings→Edge TTS. Voices: Xiaoxiao(F), Yunxi(M), Xiaohan(F-warm), Yunjian(M-mature), Aria(EN-F), Guy(EN-M), Nanami(JP-F). Falls back to browser TTS when unavailable.

## 6. AI Translation

Settings→Translate API: Enter endpoint/key/model. Select text→🌐translate(or floating 🌐). Supports DeepSeek/OpenAI compatible APIs.

## 7. Keyboard Shortcuts

Ctrl+F search / Ctrl+E toggle edit / Ctrl+S save WYSIWYG / Ctrl+B/I/U bold/italic/underline / Ctrl+Z/Shift+Z undo/redo / j↓ page down / k↑ page up / Esc close / ? help

## 8. FAQ

Q: Free? — Yes, completely free, no ads, no IAP
Q: Need internet? — Basic features work offline; translation and TTS need network
Q: Translation requirements? — Bring your own OpenAI-compatible API key; DeepSeek recommended
Q: Data location? — Browser localStorage; uninstalling clears data
Q: Supported formats? — .md/.markdown/.txt/.html/.htm
Q: PDF only one page? — Update to v2.1.1+; old bug fixed
Q: Report issues? — github.com/gzmliang/mojian-extension/issues

## 9. Permissions & Privacy

Permission: contextMenus only (right-click menu). No network/tab/history permissions. No data collection. Translation and TTS requests go directly to user-configured servers.
